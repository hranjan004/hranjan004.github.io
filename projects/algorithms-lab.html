The problem

High-level containers hide the state changes that make an algorithm work. These exercises made memory ownership, traversal state and constraints explicit.

How I approached it

I built linked-list and graph ADTs, indirect lexicographic sorting, a deck-shuffle client and a Shakespeare word-frequency index grouped by word length.

I worked on N-Queens with preset placements and an explicit search stack, alongside stack-based anagram generation and smaller simulation exercises. Debugging focused on preserving fixed constraints while undoing only speculative choices.

What changed

Created a set of command-line coursework programs with file-based inputs and outputs.

The N-Queens history includes a user-confirmed working version after a valid preset board had incorrectly returned “No solution.”

These are educational implementations, grouped here rather than presented as separate production products.

Engineering decisions

An explicit stack must retain enough state to resume a search after backtracking. A linked-list cursor must distinguish being off-list from pointing at a valid node; that invariant affects insertion and deletion alike.
