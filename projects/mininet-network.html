The problem

A network diagram does not show whether host interfaces, links and addressing behave as intended. Emulation makes those relationships inspectable.

How I approached it

I worked through a Python topology representing user devices and home equipment connected through two switches.

I configured host/link definitions and used the Mininet environment to inspect interface state and distinguish host commands from the surrounding Linux shell.

What changed

Developed the virtual-network lab setup and an operational understanding of where network commands execute.

The topology provides a repeatable environment for exploring connectivity without a physical switch bench.

This is a topology and configuration exercise; the export does not establish a verified routing policy or measured throughput.

Engineering decisions

Adding a link does not by itself solve addressing or routing. Host namespaces and switch connectivity need to be checked separately when diagnosing reachability.
