The problem

A model cannot learn reliably when labels, tensor dimensions or preprocessing disagree. These exercises focused on constructing the complete training path rather than choosing a larger architecture.

How I approached it

I worked on a simple convolutional network and a separate tabular classification notebook, connecting model outputs to loss calculation and optimizer updates.

I debugged dataset paths, numeric types, categorical preprocessing and validation predictions, checking how tensors move through the model.

What changed

Developed training and validation exercises that established the foundation for later spiking-network and energy-inference work.

The notebook history documents implementation and debugging rather than a comparative model-performance result.

No validated accuracy gain is claimed. The CNN and tabular notebook are separate coursework exercises.

Engineering decisions

Class-index labels and floating-point features have different type requirements. Validation should avoid gradient tracking and use the same fitted preprocessing as training.
