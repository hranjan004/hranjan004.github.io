The problem

Campus activities are easy to miss when information stays inside separate college communities. Our team built Slug Board to bring event discovery and participation together.

How I approached it

I owned event CRUD, the SQL schema and backend interaction logic for RSVPs, upvotes and comments.

I consolidated authentication, event and profile lookups in application code around a shared Profiles model during the move to React and Supabase.

As Sprint 2 Scrum Master, I helped coordinate the stack migration alongside feature delivery.

What changed

Delivered my event-management and database contributions to the team project.

Simplified competing user-data paths in the application code.

The archived consolidation report still lists a database migration step; the code changes do not establish that every hosted migration was completed.
