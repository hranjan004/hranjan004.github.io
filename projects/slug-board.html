The problem

Campus activities are easy to miss when information stays inside separate college communities. Our team built Slug Board to bring event discovery and participation together.

How I approached it

I owned event CRUD, the SQL schema and backend interaction logic for RSVPs, upvotes and comments.

I consolidated authentication, event and profile lookups in application code around a shared Profiles model during the move to React and Supabase.

As Sprint 2 Scrum Master, I helped coordinate the stack migration alongside feature delivery.

What changed

Implemented event CRUD, SQL updates and event-card interaction work as part of the team project.

We finished the coursework with an incomplete MVP. Backend integration was the main obstacle, and my retrospective examines how earlier shared tests and clearer interfaces could have improved delivery.

What I took from it

Our team reached 37.5% of the planned MVP. That experience made early integration, explicit API contracts and small end-to-end demonstrations more important to me than a collection of independently finished features.

Engineering decisions

The retrospective identifies the critical integration boundary: event-card interactions depended on authentication, API behavior and database queries that were not consistently verified together.

The corrective approach is to validate endpoints and database contracts before wiring the interface, integrate across user stories earlier, and keep local branches synchronized. These are lessons from the retrospective, not claims of a subsequently rebuilt MVP.
