The problem

A playlist is a useful starting point for learning how an API response becomes a structured dataset and an interpretable analysis.

How I approached it

I scoped a playlist-analysis project and explored how to organize API retrieval, data preparation and a linear-regression experiment.

I worked on repository structure and documentation before committing to a finished interface or predictive claim.

What changed

Defined the analysis direction and starter project structure.

Data access, a reproducible dataset and evaluation remain prerequisites for a finished result.

What I took from it

The proposal starts with the analysis question, but the next practical task is data access. A reproducible dataset and an evaluation plan need to come before claims about prediction or recommendation quality.

Engineering decisions

The analysis needs a clearly defined target and held-out evaluation. Descriptive playlist statistics and a predictive regression model answer different questions.
