The problem

This project connects two areas of my work: network programming in C and synchronous digital design.

How I approached it

I use the software server as a reference while exploring how request handling, buffering and board bring-up translate into FPGA hardware.

The work considers the Spartan-3E, Basys3 and Alchitry hardware mentioned in my project record.

What changed

The current outcome is a porting and bring-up effort.

The next milestone is an end-to-end HTTP request served on hardware.

A working hardware server and hardware performance figures are not yet established.

Engineering decisions

The software server provides reference behavior for request parsing and responses. Buffering, state sequencing and the hardware network interface remain design constraints to resolve before an end-to-end board demonstration.
